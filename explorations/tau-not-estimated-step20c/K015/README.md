# K = 0.15

Self-contained Job 17805-control exploration using the Joe all-region-mean
mixing-period vector at K=0.15 and the Step 20c tag-tau treatment. Run it
through the repository-level `run.sh` with
`TAU_MODE=tau-not-estimated-step20c SCENARIO=K015`.

This `bet.ini` is byte-identical to the one in the actual Job 18386 output
archive (SHA256 `670940e4815f7f10f734f5de289bbe033657169ffa764a6297d0adc693ce221f`).
The fixed log-M is `-2.54930339768360e+00`. The tag likelihood remains
negative binomial, while tau is not estimated.
